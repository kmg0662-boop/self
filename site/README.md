# PLAN_Be AI 독학 코스

코딩을 몰라도, 혼자서, 내 불편함을 해결하는 작동하는 서비스를 AI로 만들어 공개하는 8유닛 독학 코스입니다.
빌드 과정 없이 HTML, CSS, JS 파일만으로 동작합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 랜딩 페이지. 스크롤에 반응하는 장면 6개 (Plan B → Be., 선언문, 질문 비교 데모, 코스 지도, 약속, 시작) |
| `assets/landing.css`, `assets/landing.js` | 랜딩 전용 스타일과 스크롤 모션 (`prefers-reduced-motion`이면 최종 상태로 보여 줌) |
| `study.html` | 학습 앱 셸 (사이드바 진도, 모바일 서랍 메뉴) |
| `assets/content.js` | 코스의 모든 글: 유닛 8개(개념·따라하기·미션·퀴즈·막힐 때), 프롬프트, 설명서 항목, 용어, 스킬, 자가진단. **내용을 고칠 때는 이 파일만 고치면 됩니다** |
| `assets/style.css` | 학습 앱 디자인 (라이트/다크, 모바일) |
| `assets/app.js` | 해시 라우팅, 진도·미션·퀴즈 저장, 서비스 설명서 작성기, 용어 검색, 복사 버튼, 자가진단 |

## 유닛 구성

각 유닛은 같은 순서로 진행됩니다: 왜 배우나요 → 핵심 개념(비유) → 따라하기 → 미션 → 확인 퀴즈 → 막히면.

| 유닛 | 제목 | 결과물 |
|---|---|---|
| 00 | 시작하기 전에 | 내 목표 카드, 도구 계정 |
| 01 | AI와 대화하는 법 | TCREI 공식으로 쓴 내 프롬프트 |
| 02 | AI의 답을 판단하는 법 | 판단 질문 3개로 검증한 답 |
| 03 | 내 문제를 찾는 법 | 서비스 설명서 |
| 04 | 에이전트에게 맡기기 | 내 서비스의 첫 화면 |
| 05 | 고치고 다듬기 | 핵심기능 1개가 실제로 작동 |
| 06 | 공개하고 검증받기 | 공유 링크와 피드백 |
| 07 | 반복을 스킬로 | 나만의 AI 스킬 |

## 저장 방식

진도, 미션, 퀴즈, 목표, 설명서, 자가진단은 모두 브라우저 `localStorage`(`planbe:course:v2`)에 저장됩니다.
가입이나 서버가 필요 없고, 다른 기기와는 공유되지 않습니다.

## 로컬에서 보기

```bash
cd site && python3 -m http.server 8000
```
