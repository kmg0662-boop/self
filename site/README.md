# PLAN_Be AI 독학 코스

코딩을 몰라도, 혼자서, 내 불편함을 해결하는 작동하는 서비스를 AI로 만들어 공개하는 9유닛(+보너스 2) 독학 코스입니다.
유닛은 다섯 계단(대화 → 만들기 → 쌓기 → 맡기기 → 자동화)으로 묶여 있어요. 기본 코스는 STEP 3까지, STEP 4·5는 보너스예요.
빌드 과정 없이 HTML, CSS, JS 파일만으로 동작합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 랜딩 페이지. 스크롤에 반응하는 장면 7개 (Plan B → Be., 선언문, 펼치다, 질문 비교 데모, 코스 지도, 약속, 시작) |
| `assets/landing.css`, `assets/landing.js` | 랜딩 전용 스타일과 스크롤 모션 (`prefers-reduced-motion`이면 최종 상태로 보여 줌) |
| `study.html` | 학습 앱 셸 (사이드바 진도, 모바일 서랍 메뉴) |
| `assets/content.js` | 코스의 모든 글: 다섯 계단(`stages`), 유닛 11개(개념·민지의 사례·따라하기·미션·퀴즈·생각해볼 질문·막힐 때), AI 튜터 템플릿(`tutorTemplate`), 직무별 레시피(`recipes`), 프롬프트, 설명서 항목, 용어, 카테고리별 스킬(`skillCats`: GitHub 별 수·설치 명령·전후 예시 포함)과 스킬 찾기 도우미(`skillFinder`), 개발 도구 지도(`devkit`)와 허락 가이드(`approvals`), AI 사용 지도(`aimap`: 하네스 해부도, 비슷해 보이는 여섯 가지, 같은 개념 다른 이름, 도구 지도, 요금), 프롬프트 패턴(`patterns`), 화면 문구 사전(`phrases`), 자가진단. **내용을 고칠 때는 이 파일만 고치면 됩니다** |
| `assets/figures.js` | 개념 그림 8개(인라인 SVG). 개념 카드의 `fig` 키와 이름이 같아요 |
| `assets/style.css` | 학습 앱 디자인 (밝은 화면 전용, 모바일) |
| `assets/app.js` | 해시 라우팅, 진도·미션·퀴즈 저장, 간격 복습(1·3·7일), 회고, 서비스 설명서 작성기, 용어 검색·분류, 개발 도구 지도, 스킬 분류·찾기 도우미, 내 포트폴리오, 복사 버튼, 자가진단 |

## 유닛 구성

각 유닛은 같은 순서로 진행됩니다: 왜 배우나요 → 핵심 개념(비유·그림) → 민지의 사례 → 따라하기 → 미션 → 확인 퀴즈(3문항) → 스스로 점검(생각해볼 질문·AI 튜터·한 줄 회고) → 막히면.
'민지'는 회의 메모를 담당자별 할 일로 바꾸는 서비스를 만드는 가상의 학습자예요. 유닛마다 민지의 '처음 버전'(아쉬웠던 점)과 '고친 버전'이 함께 나와요.

| 유닛 | 제목 | 결과물 |
|---|---|---|
| 00 | 시작하기 전에 | 내 목표 카드, 도구 계정 |
| 01 | AI와 대화하는 법 | TCREI 공식으로 쓴 내 프롬프트 |
| 02 | AI의 답을 판단하는 법 | 판단 질문 3개로 검증한 답 |
| 03 | 안전하게 쓰기 | 데이터 신호등, 가명 처리한 자료 |
| 04 | 내 문제를 찾는 법 | 서비스 설명서 |
| 05 | 에이전트에게 맡기기 | 내 서비스의 첫 화면 |
| 06 | 고치고 다듬기 | 핵심기능 1개가 실제로 작동 |
| 07 | 공개하고 검증받기 | 공유 링크와 피드백 |
| 08 | 반복을 스킬로 | 나만의 AI 스킬 |
| 09 | 보너스 · 코딩 에이전트로 졸업하기 (선택) | 프로젝트 폴더 + CLAUDE.md + GitHub 저장소 |
| 10 | 보너스 · 반복을 자동으로 (선택) | 예약 작업 1개 + 자동화 설계도 |

유닛 id(`u0`~`u8`, `us`, `ua`)는 저장된 진도와 연결돼 있어서 바꾸지 않아요. 화면에 보이는 번호는 `no`예요.
보너스 유닛(`optional: true`)은 진도율과 '다음 유닛' 계산에서 빠져요.

## 다섯 계단

| 계단 | 유닛 | 도구 |
|---|---|---|
| STEP 1 대화 | 00–03 | 대화형 AI 앱 |
| STEP 2 만들기 | 04–07 | 웹앱 빌더, 아티팩트 |
| STEP 3 쌓기 | 08 | 스킬, GPTs, Gems |
| STEP 4 맡기기 (보너스) | 09 | 코딩 에이전트 |
| STEP 5 자동화 (보너스) | 10 | 예약 작업, Zapier·Make, 훅 |

- '내 학습' 맨 위에 지금 어느 계단에 있는지, 그 계단의 도구와 꼭 알 말이 나와요.
- 계단의 마지막 유닛 끝에는 '다음 계단 미리보기'가 나와요.
- 용어 사전은 계단별로 거를 수 있어요. 용어마다 몇 번째 계단에서 알면 되는지(`stage`), '나중에 알아도 됨'(`later`), '옛 용어'(`old`) 표시가 있어요.
- AI 사용 지도와 한 장 치트시트(인쇄 가능)는 2026년 10월 기준이에요. 도구 이름과 요금은 분기마다 확인해 주세요(`aimap.asof`).

## 스킬 가이드

- 스킬 30개를 10개 분류로 나눴어요. 한국어 글쓰기(AI 말투 윤문·맞춤법), 한국 업무·생활(k-skill), 마케팅도 들어 있어요.
- 설치 명령은 각 GitHub 저장소 README 기준(2026년 10월)이에요. 저장소가 옮겨지거나 명령이 바뀔 수 있으니 가끔 확인해 주세요.
- 스킬 찾기 도우미는 '하고 싶은 일 × 쓰는 도구'로 3개를 추천하고, 도구에 맞는 설치 방법을 보여줘요.

## 내 포트폴리오

목표 카드, 서비스 설명서, 유닛별 한 줄 회고, 진도, 자가진단 변화를 한 페이지에 모으고, 마크다운으로 복사할 수 있어요.

## 복습

유닛을 완료하면 1일, 3일, 7일 뒤에 '내 학습' 화면의 **오늘의 복습**에 그 유닛 퀴즈가 한 문제씩 다시 나와요. 틀리면 다음 날 다시 나와요.

## 스크롤 필름

선언문, 펼치다, 시작 장면 뒤에는 Higgsfield로 만든 8초 영상이 깔립니다. 영상은 자동 재생되지 않고, 스크롤 진행률이 곧 재생 위치가 됩니다.
영상과 시작·끝 사진은 Higgsfield CDN 주소를 그대로 씁니다(`index.html`의 `.film-media`). 영상이 아직 안 불러와졌으면 시작·끝 사진을 겹쳐 보여 주고,
움직임 줄이기 설정이면 끝 사진 한 장만 보여 줍니다.

## 화면 모드

사이트는 밝은 화면 전용입니다(`color-scheme: light only`). 기기가 다크 모드여도 같은 화면으로 보여서, 배경 영상과 글자 대비를 한 가지 기준으로만 관리하면 됩니다.

## 저장 방식

진도, 미션, 퀴즈, 목표, 설명서, 자가진단은 모두 브라우저 `localStorage`(`planbe:course:v2`)에 저장됩니다.
가입이나 서버가 필요 없고, 다른 기기와는 공유되지 않습니다.
