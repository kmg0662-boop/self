# 말랑몬 선생님

초등 저학년이 **AI를 직접 가르쳐 보며** "AI는 예시로 배운다"를 몸으로 익히는 태블릿용 웹 게임이에요.
아이는 선생님, 짝꿍 말랑몬은 보여 준 만큼만 아는 작은 AI예요. 빌드 없이 HTML·CSS·JS 파일만으로 동작해요.

- 주소: 배포된 사이트의 `/monster/`
- 기기: 태블릿 가로 화면(갤럭시 탭 기준 1280×800). 다른 화면에서는 통째로 늘이거나 줄여서 맞춰요.
- 혼자 하기: 모든 안내를 짧은 글 + 목소리(기기 음성)로 읽어 주고, 다음에 누를 곳을 손가락이 가리켜요.

## 놀이 흐름과 배우는 것

| 순서 | 아이가 하는 일 | 배우는 것 |
|---|---|---|
| 누가 할까 | 내 이름 고르기, 내 모습 꾸미기(머리·피부·옷·모자·안경) | 내 캐릭터라는 애착 |
| 알 고르기·부화 | 누르기, 두드리기, 열매 끌어다 주기 | 화면 조작(탭·드래그) |
| 첫 배틀 | 아무것도 안 가르친 채로 내보내 봄 → 짐 | **가르치지 않으면 AI는 아무것도 모른다** (왜 배워야 하는지 먼저 느끼기) |
| 가르치기 (놀이터 학교) | 말랑몬을 불·물·풀 집으로 끌어다 놓기 | 사람이 정답을 알려 준 예시 = 학습 데이터 |
| 동네 탐험 | 가고 싶은 곳을 눌러 걸어 다니다 야생 말랑몬과 마주치면 배틀 | AI는 **본 것 중 가장 닮은 것**으로 판단한다 |
| 틀렸을 때 | 헷갈린 친구가 다음 수업 카드로 돌아옴 | 틀린 예시를 다시 가르치면 나아진다 |
| 진화·도감 | 레벨 3, 6, 10에서 진화 / 동물·곤충·공룡 9종 모으기 | 수집·성장 동기 |
| 전설 도전 | 한 타입 3종을 다 모으면 전설이 깨어남. 맞힐 때마다 몸 색을 바꿔 속이려 듦 | 겉모습(색)에 속지 않고 진짜 단서를 보는 AI |

색은 다른 타입 같은데 머리 장식은 진짜 타입인 말랑몬이 섞여 나와요. 짝꿍은 처음엔 색에 속지만,
예시가 쌓이면 "색보다 머리를 봐야 하는구나!"를 스스로 알아채요(그 순간에만 대사가 나와요).

## 아이 이름과 여러 명이 쓰기

- 아이마다 따로 저장돼요(최대 4명). 시작하면 "누가 할까?"에서 고르거나 새로 만들어요.
- 이름과 꾸민 모습은 **그 기기에만** 저장돼요. 코드나 서버에는 남지 않아요.
- 아이가 글자를 치지 않아도 되게 하려면, 주소 끝에 `#names=이름1,이름2`를 붙여 한 번만 열어 주세요.
  그 이름들이 "누가 할까?"에 고르기 카드로 나와요. (`#` 뒤는 서버로 전송되지 않아요)

## 우리 동네 지도

제주 바닷가의 아파트 단지를 본떠 그렸어요. 위쪽이 바다와 등대, 가운데가 7층 아파트 단지와 놀이터,
왼쪽이 귤밭과 큰 팽나무, 오른쪽이 공원과 연못, 아래쪽이 오름과 한라산이에요. 돌담과 돌하르방도 있어요.
실제 배치도를 그대로 옮긴 것은 아니에요. 건물 위치는 `assets/world.js`의 `BLOCKS`만 고치면 바뀌어요.

- 누른 곳으로 걸어가고, 누르고 있으면 손가락을 따라가요. 건물에 막히면 알아서 모퉁이를 돌아가요.
- 화살표가 다음에 갈 곳(가까운 야생 말랑몬, 학교, 깨어난 전설)을 가리켜요.
- 하트가 다 떨어지면 집에서 쉬고 다시 시작해요.

## 짝꿍의 두뇌는 진짜로 배워요

`assets/brain.js`에는 정답을 미리 넣어 둔 곳이 없어요.

- **기억**: 아이가 가르친 예시(색·머리 장식·꼬리 장식 + 타입)만 저장해요.
- **맞히기**: 처음 보는 말랑몬과 가장 닮은 기억 3개를 찾아 다수결로 정해요(k-최근접 이웃).
- **단서 고르기**: 기억을 한 마리씩 가려 보며 "이 단서 하나로도 타입을 맞힐 수 있나"를 시험해, 잘 맞는 단서를 더 믿어요.
- **똑똑함 점수**: 늘 같은 시험지(야생 150마리)에서 맞힌 비율이에요. 그래서 가르친 뒤 점수가 가끔 조금 내려갈 수도 있어요(실제 AI도 그래요).

대략 예시 3개에 79점, 15개에 97점, 25~30개에 100점 근처까지 올라가요.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 무대 하나와 스크립트 불러오기 |
| `assets/brain.js` | 학습하는 두뇌, 말랑몬 생김새 만들기 |
| `assets/monsters.js` | 짝꿍(진화 4단계)과 야생 말랑몬 그림(SVG). 부위가 나뉘어 있어 CSS로 숨쉬기·깜빡임·꼬리 흔들기를 줘요 |
| `assets/art2.js` | 전설 말랑몬 3마리(공룡왕·바다 용·장수풍뎅이)와 주인공 아이 그림 |
| `assets/world.js` | 동네 지도: 땅 그림, 건물·나무·돌하르방, 못 지나가는 곳, 들어가는 곳 |
| `assets/audio.js` | 효과음(파일 없이 합성)과 읽어 주기 |
| `assets/game.js` | 화면과 진행, 지도 걷기, 저장(`localStorage`의 `mallangmon.v2`) |
| `assets/game.css` | 화면 배치와 움직임 |

캐릭터는 모두 이 게임을 위해 새로 그린 것이에요. 기존 게임의 캐릭터·이름·그림은 쓰지 않아요.

## 점검

주소 끝에 `?fast=1`을 붙이면 대기 시간이 줄고 버튼이 자동으로 눌려서 끝까지 빠르게 돌려 볼 수 있어요.
콘솔의 `__mm.state`로 저장 상태를, `__mm.go('map' | 'lesson' | 'dex' | 'who')`로 화면을 바로 열 수 있어요.
